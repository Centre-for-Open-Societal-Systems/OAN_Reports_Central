## Shell
- Sidebar: Report Center logo (green sprout), REPORTS (Report Library, Custom Reports, Schedule), DASHBOARDS (Registries ↗, Access to Credit ↗)
- Top: centered Search reports (/), bell, avatar DR, ATI Director
- Soft light background; primary green; orange accent for active category tab

## Report Library
- Title + “+ New Custom Report”
- Category tabs with counts: Access to Credit (11), Farmer Registry (8), Livestock (6), Crop Sown (6), Grievance (12)
- KPI summary row for selected category
- Example Data + Open Dashboard
- Filter chips + Grid/List toggle
- 4-col report preview cards: tag, title, expand, chart preview, frequency footer

## Access to Credit — Report Library (ATI Credit Manager)
- Role chip: CM / ATI Credit Manager
- KPIs (example data in design): Farmers Enrolled 39 · Applications 32 · Loans Approved 4 (12.5%)
- Filters: All (11) / Applications (5) / Providers and Places (3) / Consent and Data Sharing (3)
- Sidebar DASHBOARDS shows Access to Credit; Settings in sidebar footer
- Cards:
  - Applications: Credit Programme Summary, Loan Applications by Status, Loan Applications by Product, Monthly Application Cohorts, Application Decline Reasons
  - Providers and Places: Applications by Credit Provider, Credit Providers Onboarded, Credit Activity by Location
